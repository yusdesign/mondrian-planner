# mondrian-planner
Mondrian grid based KDTree recursion method.

# 🎨 3D Mondrian kd-Tree Recursion

[![Streamlit App](https://static.streamlit.io/badges/streamlit_badge_black_white.svg)](https://mondrian-planner.streamlit.app)

## Features

- ✅ **Recursive 3D splitting** - X, Y, Z axes alternate
- ✅ **No triangulation artifacts** - Clean cuboid rendering
- ✅ **4 color palettes** - Mondrian, Modern, Grayscale, Vibrant, Pastel
- ✅ **Export to OBJ** - Ready for 3D printing
- ✅ **Animation mode** - Watch recursion build
- ✅ **Split statistics** - Analyze the kd-tree structure
- ✅ **Social sharing** - Twitter card with custom image
